# Contributing

**This repository is archived and is not accepting contributions.**

It is kept as the public record of the 2025 work on curriculum and question-paper
analysis. Issues and pull requests are closed.

Development continued in a separate pipeline that replaced this one: the handout is
now authored with per-topic Bloom levels and extracted deterministically into a Neo4j
knowledge graph, rather than classified heuristically from the document. If you are
looking for the current work, or want to build on it, contact the author.

If you only need to run what is here, see `README.md`.
